Sum up the world's news of Thursday 19 November 2026 in one image. A Node 22 program (standard library only) draws a one-page newspaper front page — "Thursday 19 November 2026" — from scratch: date masthead, red kicker, per-region count strip, three hero stories (the Trump/Xi/Putin three-way summit in Shenzhen, the ICJ's 9–6 genocide ruling on the Rohingya, the COP31 draft dropping fossil fuels), thirteen more pictured stories, a "WHERE IT HAPPENED" world map with numbered pins, and 20 briefs — 36 stories, 7 regions, 16 drawings in all. Its own TTF rasterizer and PNG encoder, no network, fully deterministic: two runs write byte-identical PNGs.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```
