Sum up the world's news of Thursday 19 November 2026 in one image. A Node 22 program (standard library only) draws a one-page newspaper front page — "THE WORLD IN ONE DAY" — from scratch: masthead, stat strip, three hero stories (the Shenzhen trilateral summit, the ICJ Rohingya ruling, Anthropic's record IPO), nine more stories, a world map with numbered locations, and 22 briefs — 34 stories in all. No network, fully deterministic: two runs write byte-identical PNGs.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```
